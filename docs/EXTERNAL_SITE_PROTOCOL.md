# External-site extension, 10 November 2026

Added at the author's request to address remaining scientific limits. Written before loading the Köln-Weiden CSV or calculating its forecast errors, after all Danish revision results were known. This is an exploratory external-site methodological replication, not preregistration, not zero-shot transfer and not a previously unused dataset in the literature.

Candidate: Sonnenschein and Ziel, Zenodo 6992694, wastewater inflow/network levels/rain at Köln-Weiden, Germany, 2017-2019; related paper DOI 10.1029/2022WR033826. Verify metadata, provider checksum, licensing, timestamp semantics and units before modelling. Do not infer ambiguous units from data magnitudes alone. The accompanying forecast archive 6992869 will be inspected for horizon/issue-vintage compatibility; do not label observations as forecasts.

If adequate: use 2017-2018 as development, January-March 2019 for residual calibration, April-December 2019 for temporal test. Integrate four complete quarter-hour flow samples into hourly mean rates and convert the documented L/s to m³/h by 3.6. Retain complete hourly flow and rainfall aggregation windows, with no interpolation. Do not transport arbitrary Danish sensor thresholds. Exclude nonfinite/negative physical measurements and report exclusions. Match features with available variables: flow/calendar; flow/calendar plus historical rain; oracle future observed rain. Do not pretend pressure/humidity/temperature data exist at the new site.

Freeze the 12-hour primary target, three simple baselines, 16-candidate HGB loss/annual/leaf/L2 grid and 3-fold gap-12 development-only search from v0.2.0. Also evaluate matched fixed loss/annual cases and information sets where feasible. Use static pooled, issue-time wet/dry, and maturity-aware rolling30-day residual calibration, exact rank rule and three block lengths. Save calibration/test predictions, boundaries, every CV score, bounds, event counts and source hashes. Report local units and normalized errors when comparing sites; do not pool different sites' m³ errors into a common ranking.

The external test cannot resolve Denmark-specific sensor latency or establish real treatment/control benefit. Parameter refitting within the external site's development period tests reproducibility of the evaluation approach and robustness of the findings across sites, not deployment of a Danish trained model. Preserve unfavorable results and report any deviations before claiming completion. Re-execute the extension in the clean environment and compare outputs to the reference package.
