# Retrospective revision protocol v0.2.0

Recorded 2026-11-10 before executing the revision pipeline. This is not preregistration: the original outcomes and audit sensitivities have already been inspected. All revision analyses are retrospective and exploratory. Preserve v0.1.0 and the audit as provenance; do not label any reused interval as a new independent test.

Target: integrate archived hourly flow-rate observations over the next 12 hours using a one-hour step. This approximates cumulative volume pending provider confirmation of aggregation semantics. Historical information is assumed available at the issue time; delays of 1 and 2 hours will be examined. No plant-control, pollutant-removal or energy benefit is inferred.

Data: Zenodo record 15301164 v1, observations.zip. Retain original QC and complete target windows; add no-QC sensitivity. Retain original primary elapsed-time 60/20/20 partitions and 6/24-hour sensitivities. Add three nonoverlapping 60-day test periods beginning 2024-08-15, 2024-10-15 and 2024-12-15, with preceding 45-day calibration and expanding training. Exclude labels reaching the next partition or test end. Earlier periods overlap data examined previously; these are temporal robustness analyses, not external validation.

Models: persistence, 24-hour mean, previous-day profile; ridge (alphas 1,100,10000); HGB flow/calendar, HGB historical weather, HGB oracle. HGB grid: loss squared_error/absolute_error, annual sine/cosine retained/removed, max_leaf_nodes 7/15, l2_regularization 1/10; max_iter150, learning_rate0.05, min_samples_leaf30, early_stopping false. Three expanding folds with gap equal to horizon, imputation/scaling fitted in folds. Grid selection uses development MAE only. Preserve a fixed legacy historical HGB (squared_error, annual included,7 leaves,L2=10) and matched-information fixed HGBs (absolute_error, annual included,7 leaves,L2=10) for diagnostic comparisons. No configurations dropped because of unfavorable results.

Intervals: exact finite-sample order statistic k=ceil((n+1)*0.9), infinity if k>n, explicit error on empty/nonfinite input. Pooled static, wet/dry static and 30-calendar-day rolling residual calibration. At issue t, only residuals whose targets mature by t (issue+h<=t) may enter rolling calibration; at least30 residuals, otherwise use the static calibration pool. Historical outer predictions are never fitted on calibration/test outcomes. Interval results are empirical, without exchangeability or conditional-coverage guarantees.

Uncertainty: paired MAE differences, including mean24 versus persistence and learned/oracle versus mean24. Circular fixed-length blocks confined to contiguous valid issue-time runs, uniformly sampled starting positions; B=24/48/168,2000 resamples. Label percentile ranges as approximate bootstrap sensitivity intervals, not confirmatory 95% confidence guarantees under nonstationarity. Audit equal marginal inclusion and demonstrate method behavior on explicitly synthetic stationary AR(1) sequences as a diagnostic only.

Event analysis: retain original training-90th-percentile outcome-tail definition. Report every contiguous high-volume episode, leave-one-episode-out and all horizon phases of nonoverlapping outcomes. Do not call episodes independent storms. Also report issue-time wet/dry strata. Rainfall-defined events are exploratory: hourly rain>0, split storms after >=12 consecutive dry hours; map high windows to storms only if correspondence can be defended, otherwise avoid claiming independent meteorological events.

Sensitivity: primary12h selected hyperparameters fixed for re-fits with annual columns ablated, data delays1/2h, and no sensor screening. Compare on common valid test issue times. Persist all calibration/test predictions, interval bounds, model grid/fold results, splits, retention, versions and hashes. Verify raw-derived target sums, boundaries, numerical tables, interval construction, feature and rolling-calibration causality. Comparison must fail on empty/missing files or numeric differences. Independent-site data, sensor latency/aggregation documentation and human scientific review remain outstanding.
